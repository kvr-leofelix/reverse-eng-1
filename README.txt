CS213 - Reverse Engineering Lab
Windows Environment Setup

1. Install Python 3.10 and select "Add Python to PATH".
2. Keep setup.bat and requirements.txt in the same folder.
3. Double-click setup.bat.
4. Wait for "SETUP COMPLETED SUCCESSFULLY".
5. For the lab, open Command Prompt in this folder and run:
   venv\Scripts\activate
   jupyter notebook

If setup fails, take a screenshot and contact the CS213 TA team.

NOTE: opencv-python is pinned to 4.7.0.72 because that is the
available 4.7.0 OpenCV Python release for this setup.
